## Как читать дневник

Каждая страница содержит исходное задание, фактическую реализацию, API-контракт, архитектуру, проверки и ссылки на относящиеся к ней файлы. Проект развивается в общих каталогах `ios` и `backend`, а тег `day-XX` фиксирует историческое состояние на момент сдачи — поэтому код не дублируется по папкам заданий.

Для быстрой проверки достаточно выбрать день в таблице. Для подробного ревью можно перейти в раздел **«Код»** на его странице или открыть соответствующий Git-тег.
