# День 22 — Первый RAG-пайплайн

## Задача

Реализовать цепочку `вопрос → поиск фрагментов → объединение контекста → LLM` и сравнить ответ модели без RAG с ответом по локальной базе знаний. Подготовить 10 контрольных вопросов с ожидаемыми источниками.

## Реализация

Один и тот же вопрос проходит два независимых маршрута:

1. **Baseline** — модель отвечает без документов и обязана признать отсутствие точных данных;
2. **RAG** — вопрос превращается в локальный embedding, cosine similarity выбирает пять structural chunks, после чего найденный контекст передаётся в LLM.

Интерфейс показывает ответы рядом, длительность, токены и полный retrieval trace. Поэтому разницу можно оценивать не по обещанию системы, а по фактически переданным модели файлам.

Контрольный набор из 10 вопросов покрывает HTTPS, MCP, cron, SQLite, форматы ответа, task state, context strategies и навигацию Web-приложения. Для каждого вопроса заранее записаны ожидаемые пути источников.

Если индекс ещё пуст, RAG-сервис строит его автоматически перед первым поиском.

## Как записать видео

1. Открыть [День 22](https://176-53-173-246.sslip.io/#day-22).
2. Выбрать один из вопросов `Q01–Q10` или ввести свой вопрос о проекте.
3. Нажать **«Запустить A/B сравнение»**.
4. Сравнить карточки **«Без RAG»** и **«С RAG»**.
5. Показать время и токены обоих ответов.
6. Раскрыть найденные chunks и проверить source, section и similarity score.
7. Повторить с вопросом, точного ответа на который модель не могла знать без репозитория.
