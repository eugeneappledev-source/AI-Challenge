# День 18 — Автоматический запуск агента

## Задача

Настроить периодический запуск агента через cron и сохранять результат так, чтобы его можно было проверить после выполнения фоновой задачи.

## Реализация

В Docker Compose добавлен отдельный контейнер `radar-scheduler`. В нём работает системный `crond`, который каждый день в 08:00 UTC отправляет внутренний авторизованный запрос агенту.

Сценарий одного запуска:

1. cron вызывает endpoint фонового задания;
2. Research Agent подключается к MCP-серверу;
3. агент получает актуальные новости через `search_business_news`;
4. LLM выделяет осторожные бизнес-гипотезы, первые шаги и риски;
5. весь результат сохраняется в SQLite;
6. Web-интерфейс читает сохранённую историю без повторного LLM-вызова.

Кнопка **«Запустить сейчас»** выполняет тот же сценарий с меткой `manual`. Она нужна для короткой демонстрации, а расписание продолжает работать независимо от открытого браузера.

## Как записать видео

1. Открыть [День 18](https://176-53-173-246.sslip.io/#day-18).
2. Показать cron expression, следующий запуск и SQLite persistence.
3. Нажать **«Запустить сейчас»** и показать понятный индикатор выполнения.
4. После завершения открыть последнюю сводку: источники, идеи, первый шаг и риск.
5. Прокрутить историю и обратить внимание на причину запуска `manual` или `cron`.
6. Сделать вывод: cron будит агента, агент вызывает MCP, а результат сохраняется независимо от интерфейса.
